# No ownership no innovation.

We believe AI is a general machine. It excels at the common patterns. However, we believe when you work on the unknowns, AI struggles. Like how AI struggles at understanding what Walker is, because it did not exist before.

We call contributors to respect and uphold the foundation principles of Walker. We built this project for those who still care. Neglecting is not an option. If you want to explore the power of agent-maintained projects, feels free to fork & rebrand the project.

As for us, we still write code by hand because we believe that is the pace of information consumption, that is how we own our work. We still write document by hand because we feels alive painting the future we believe in.

# When to use AI

The recommended tasks for AI are:

- Boring refactors
- Find bug
- Suggest solution
