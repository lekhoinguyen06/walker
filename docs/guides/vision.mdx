## Why

The world of MCP protocol and personal agent is amazing. There is no denying the power of AI and the potential it holds.

However, we hate the blindness that comes with it. When we ask the agent to do something, it loads, shows some thoughts, and says it is done. We have no idea what changes or what it is doing. 

We believe the future is about agents who works "with" us, rather than working "for" us. We are build the world for those who care, so we decided to build Walker. Walker are a set of libraries that allows backend controlled interactive agents.

## How

We are building libraries for both frontend and backend frameworks to integrate Walker. Basically, we are just transferring JSON objects. The idea is: user prompt, Client send Map, Server return Action, repeat.
