# Components

We have many out-of-the-box components, full Markdown and MDX support, and allow full customization for your docs. Here are a few of them — edit them in place, or add more from the editor.

## Callouts

<scalar-callout type="info">

Callouts come in neutral, success, info, warning, and danger.

</scalar-callout>

## Cards

<scalar-grid cols="2">

<scalar-card title="On their own" icon="phosphor/regular/cards">

A card takes a title, an icon, and any Markdown you like in its body.

</scalar-card>

<scalar-card title="Or in a grid" icon="phosphor/regular/squares-four">

Wrap cards in a grid to lay them out in columns.

</scalar-card>

</scalar-grid>

## Tabs
